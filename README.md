# Project Management App 🎯

A sleek, lightweight, and intuitive project management application inspired by Windows To-Do. This app allows users to seamlessly organize their workflows, break down goals into manageable projects, and track individual tasks by their due dates.

---

## ✨ Features

- **Full Project Lifecycle (CRUD):** Easily Create, Update, Rename, and Delete projects via an intuitive context menu.
- **Task Management:** Add individual tasks to specific projects and assign critical due dates to stay on track.
- **Persistent Storage:** Your workflow is safely preserved across page reloads using browser `LocalStorage`.
- **Seamless UX:** Includes asynchronous router mechanics, bubbling prevention for misclicks, and snappy notification alerts.
- **🚀 Future Roadmap:** Built with scalable architecture, ready to transition from client-side storage to a full cloud database.

---

## 🛠️ Tech Stack

- **Frontend Core:** React
- **Routing & Data Loading:** React Router
- **Styling:** Tailwind CSS (Focusing on a minimalist, clean "Stone" aesthetic)
- **Icons:** Lucide React
- **Notifications:** React Hot Toast

## 🚀 Getting Started

Follow these simple steps to get a local copy of the project up and running.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/3bd-allah/ManagementApp.git
   

2. **Navigate into the project directory:**
  ```bash
    cd YOUR_REPO_NAME 

```
3. **Install the dependencies:**
```bash
  npm install

```
4. **Start the local development server:**
```bash
  npm run dev
